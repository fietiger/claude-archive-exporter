Privacy Policy

Last updated: 2026-10-21

The Claude 会话归档导出 browser extension helps users export Claude conversations to a local ZIP archive. This extension is designed to run only when you visit https://claude.ai/chat/* pages.

Data processed

The extension reads the currently open Claude conversation through claude.ai website APIs that are already available to your logged-in browser session. It may include conversation messages, attachments, artifacts, file metadata, and raw JSON data.

Where data goes

DataDestination
Conversation content and filesYour local browser ZIP download only
No analytics, no telemetry, no third-party requestsNone

Permissions

The extension requests host_permissions for https://claude.ai/* so it can read the Claude page and call Claude's own same-origin APIs. It does not request broad browser permissions such as storage, cookies, or downloads.

User control

You can remove the extension at any time from your browser extension settings. The extension does not persist data between sessions.

Contact

Report issues or request privacy information: GitHub Issues.

Short declaration for marketplaces:
This extension does not collect personal data. It only processes Claude conversation content in the user's logged-in browser session and packages it into a local ZIP file that the user downloads. It does not transmit data to third parties.
